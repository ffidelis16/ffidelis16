# Blip: design web e CRO

![Exemplo público de página Blip em que trabalhei.](../assets/blip.jpg)

Trabalhei por seis anos na Blip com sites e páginas para conversão, conectando design, implementação, análise e experimentação. Co-liderei a reconstrução do ecossistema web em três idiomas.

## Resultado de 2025

A página de conversão do site institucional atingiu uma taxa superior a **16%**, com aumento aproximado de **170%**, por meio de um ciclo contínuo de testes, ajustes, SEO e aplicação dos aprendizados.

Esse resultado se refere à página de conversão do site institucional. Não é atribuído a um teste isolado, ao site inteiro ou à página de WhatsApp mostrada como exemplo visual.
